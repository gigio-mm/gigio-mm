## 🏆 Featured Project: Atlas Oral-Maxillofacial

**[View Repository](https://github.com/gigio-mm/Atlas-Oral-and-Maxillofacial)**

An interactive anatomical atlas for dentistry, solving the "static textbook" problem with a high-performance web engine.

* **Engineering Highlight:** Implemented an **Image Pre-loading Engine** to ensure zero-lag interactions during muscle/bone overlays.
* **The Stack:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4.
* **Key Achievement:** Created a typed data layer for 25+ anatomical structures with dual display modes (Overlay & Side-by-Side).
